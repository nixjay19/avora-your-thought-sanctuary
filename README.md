# Avora: Your Thought Sanctuary

I want to explore building an app called Avora in Lovable.



Do NOT start building yet. Stay in Planning Mode and help me think through the product, UX, architecture, data model, and feasibility first.



Avora is intended to be a personal, private, offline-first-feeling sanctuary for capturing thoughts and gently taking care of yourself.



The core experience has three parts:



1. THOUGHTS

A frictionless capture space where I can type or speak anything that's floating around in my head.



I should never have to decide what something is before capturing it.



Avora preserves my original words and can intelligently interpret them as:

- Note

- Task

- Idea

- Reminder



Voice capture is important. I want speaking to feel like a first-class interaction, not simply a microphone attached to a text field.



The core promise is:

"You don't have to organize it first."



The goal is to capture a thought in under five seconds.



2. SANCTUARY

A gentle space for taking care of myself.



It should support:

- Nourish & Eat

- Medication

- Supplements

- Move



I should be able to configure:

FOOD

- foods I avoid

- foods I don't eat

- foods I like

- preferred cooking effort



MEDICATION

- medication name

- dose

- reminder time

- frequency

- optional notes



SUPPLEMENTS

- supplement name

- dose

- reminder time

- frequency

- optional notes



MOVE

- preferred movement types

- optional reminder

- preferred time

- frequency



Meal suggestions should use the person's saved preferences.



I want meal ideas to be inexpensive to operate. A local/curated meal library should handle normal suggestions, with AI only used when genuinely useful.



Care should never feel like a health compliance dashboard.



Avoid:

- calories

- weight tracking

- streaks

- guilt

- missed-goal warnings

- XP

- percentages

- achievement spam



The language should be gentle:

"I ate"

"I took it"

"I took them"

"I moved"



After completion, something like:

"Tended with care ✨"



Notifications should be gentle and useful.



3. WORLD

This is the part I want to explore carefully.



Originally I imagined an egg that eventually hatches into a fantasy creature.



I've changed my mind about making the egg the central mechanic.



I now think the user should have a separate World experience containing an original fantasy creature and its own little environment.



The creature should NOT be a generic mascot, Tamagotchi clone, Pokémon-like creature, or copyrighted character.



It should feel:

- magical

- curious

- expressive

- slightly mysterious

- adorable without being childish

- emotionally warm



The World should feel like a tiny place the user visits.
